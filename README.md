# Tree Shake Products

A SMAPI mod which gives mature trees a 5% chance to drop one of their tapper products when shaken.

## Drops

| Tree | Extra product |
| --- | --- |
| Maple Tree | Maple Syrup |
| Oak Tree | Oak Resin |
| Pine Tree | Pine Tar |
| Mahogany Tree | Sap |
| Mystic Tree | Mystic Syrup |

The chance is rolled only on the tree's first shake of the day. Later shakes of the same tree cannot produce another product; the tree becomes eligible again the next day. All normal shake drops are preserved.
